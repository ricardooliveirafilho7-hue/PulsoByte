Este arquivo demonstra o fluxo de rascunhos: com `status: "draft"`, o artigo aparece apenas
durante o desenvolvimento (`npm run dev`) e é excluído do build de produção, das listagens, da
busca e do sitemap.

## Como usar este modelo

1. Duplique este arquivo com um novo nome.
2. Preencha o frontmatter — título, descrição, slug único, categoria e datas.
3. Escreva o conteúdo usando os componentes do portal.
4. Quando terminar, troque `status` para `"published"`.

## Componentes disponíveis

Callout, KeyTakeaways, ProsAndCons, ComparisonTable, Sources, Figure, Quote, StepByStep e
AdSlot. Veja os artigos publicados para exemplos de uso de cada um.
