# Relatório Final

Produza sempre ao fim da execução, usando `templates/execution-report.md`.
A execução só está completa com o relatório.

Deve conter: data editorial, turno, automationRunId, branch padrão, SHA base,
tema, título, slug, topicKey, fontes, imagens, branch, commit, PR, validações
executadas e seus resultados, integração, deployment, URL final e etapa atual.

Se parou antes do fim: declare a etapa exata onde parou, o motivo, e o que é
preciso para retomar (via mode=resume, mesmo automationRunId).

Seja factual. Não declare sucesso de etapa não concluída. "Verde" de workflow não
é prova de tarefa concluída — só a verificação da página real é.
