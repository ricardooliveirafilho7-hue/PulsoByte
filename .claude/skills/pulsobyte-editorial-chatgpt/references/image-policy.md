# Política de Imagens

## Prioridade de origem
1. Press kits oficiais → 2. Blogs oficiais → 3. Páginas oficiais de produto →
4. Páginas oficiais de empresa → 5. Repositórios oficiais → 6. Contas oficiais →
7. Materiais de imprensa → 8. Imagens com licença compatível →
9. Capturas próprias permitidas de páginas públicas →
10. Bancos gratuitos com licença adequada, só quando fizer sentido.

## Proibições
- Não usar imagem genérica só para preencher.
- Não apresentar imagem gerada por IA como registro real do acontecimento.
- Não usar arquivo com marca d'água de banco pago.
- Não copiar imagem de matéria de outro veículo sem autorização clara.

## Verificação por imagem
Página de origem, proprietário, relação com o tema, permissão de uso, crédito
exigido, resolução, proporção, qualidade, ausência de marca d'água inadequada,
ausência de conteúdo enganoso. A imagem principal deve representar o assunto
imediatamente.

## Processamento (padrão do projeto)
🔍 CONFIRMAR NO REPO: formato (ex.: WebP), dimensões e pasta de imagens reais.
Baixar → salvar no local padrão → converter ao formato do projeto → redimensionar
sem deformar → comprimir sem perda visual excessiva → remover metadados
desnecessários → nome descritivo → alt text específico → registrar fonte/crédito →
conferir caminho no artigo → confirmar renderização.

## Nomes
Bons: `openai-novo-recurso-chatgpt.webp`, `meta-app-inteligencia-artificial.webp`.
Ruins: `image1.png`, `foto-final-2.jpg`.

## Fallback
Se nenhuma imagem segura for encontrada: NÃO invente origem. Sinalize no PR e use
o fallback do projeto, ou pare a etapa de imagem para curadoria manual.
